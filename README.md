One picture of food, judged on how delicious it looks: a single hero ingredient — a glistening honeycomb with honey dripping onto dark slate in warm light. The image is rendered locally at build time (draw.py, Pillow) as a 1024×1024 PNG; `main.ts` copies the committed `entry.png` to the output directory with Node stdlib only.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
